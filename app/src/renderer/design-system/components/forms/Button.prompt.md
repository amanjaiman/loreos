Primary action control — use for the main call-to-action; pair with `secondary`/`outline`/`ghost` for supporting actions and `danger` for destructive ones.

```jsx
<Button variant="primary" icon="sparkles">Summon Lore</Button>
<Button variant="outline" iconRight="arrow-right">Continue</Button>
<Button variant="ghost" size="sm">Dismiss</Button>
<Button variant="danger">Delete</Button>
```

Variants: `primary` (default), `secondary`, `outline`, `ghost`, `danger`. Sizes: `sm` · `md` · `lg`. Props: `icon`, `iconRight` (Lucide names), `fullWidth`, `disabled`, `as`.
